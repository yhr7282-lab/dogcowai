# 다섯 시 경제 (dogcowai.com)

https://dogcowai.com

경제·주식·AI·반도체·자동차 뉴스를 날짜별로 요약해 쌓는 정적 사이트입니다. GitHub Pages로 무료 호스팅됩니다.

## 폴더 보는 법

| 이름 | 하는 일 | 직접 고치나요? |
|---|---|---|
| `index.html` | 홈페이지 | 아니요. 자동 생성됩니다. |
| `news/` | 지난 브리핑 목록과 날짜별 페이지 | 아니요. 자동 생성됩니다. |
| `content/` | 매일의 공개용 내용 파일 (`2026-10-13.json` 등), 고정 페이지(`pages/`) | 예. 하루에 파일이 하나씩 늘어납니다. |
| `about/`, `sitemap.xml`, `robots.txt`, `feed.xml` | 소개 페이지와 검색용 파일 | 아니요. 자동 생성됩니다. |
| `assets/style.css` | 디자인 (색, 글자 크기, 배치) | 디자인을 바꿀 때만 |
| `tools/` | 페이지를 만드는 프로그램과 테스트 | 아니요 |
| `docs/` | 설계 문서, 내용 파일 형식 설명 | 참고용 |
| `CNAME`, `.nojekyll` | 도메인 연결 | 절대 건드리지 않습니다 |
| `보관/` | 이 컴퓨터에만 있는 보관 폴더 (사이트와 저장소에 올라가지 않음) | 아니요 |

## 매일 업데이트하는 법

Claude Code에게 이렇게 말하면 됩니다.

> 오늘 브리핑으로 dogcowai 사이트 업데이트해줘

안에서는 이 순서로 진행됩니다.

1. 원본 브리핑에서 **공개해도 되는 내용만 골라** `content/오늘날짜.json`으로 옮긴다.
2. `python3 tools/build.py`로 홈·목록·그날의 페이지를 다시 만든다.
3. 미리보기를 확인한 뒤 승인하면 GitHub에 올린다. 1~2분 뒤 dogcowai.com에 반영된다.

자세한 절차는 `CLAUDE.md`, 내용 파일의 형식은 `docs/content-format.md`, 상황별 운영 방법은 `docs/automation.md`, 검색·통계·수익화 준비는 `docs/growth.md`에 있습니다.

## 직접 실행해 보기

```
python3 tools/build.py           # 모든 페이지를 다시 만든다
python3 tools/build.py --check   # 검사만 하고 파일은 쓰지 않는다
python3 tools/test_build.py      # 테스트
python3 tools/test_pipeline.py   # 수집·링크 도구 테스트
python3 tools/check_links.py content/2026-10-13.json   # 출처 링크가 열리는지 검사
```

`index.html`을 더블클릭하면 인터넷 없이도 이 폴더의 사이트를 열어 볼 수 있습니다. 폰트만 인터넷에서 받아 옵니다.

## 공개 규칙

이 저장소와 사이트는 누구나 볼 수 있습니다. **공개 입력에는 개인 내용을 두지 않습니다.**

- 개인 맞춤 내용(개인 행동 지침, 개인 자산·보유·구직·건강 같은 사생활 내용)은 처음부터 `content/`에 옮기지 않습니다. 개인용 원본에만 둡니다.
- 일부만 가리는 방식("비공개 표시")은 쓰지 않습니다. 입력에 `private` 표시가 있으면 생성이 실패합니다.
- 부동산 매입가·월세·보증금·분양가, 채용 공고번호 같은 패턴은 금지 패턴(`content/_site.json`의 `blocklist`)으로 검사합니다. 입력 JSON의 모든 문자열과 생성된 HTML 전체에서 찾고, 걸리면 아무것도 쓰지 않고 멈춥니다.
- 특정 이름·번호처럼 공개 저장소에 적을 수 없는 금지 단어는 이 컴퓨터의 `보관/blocklist.local.txt`에만 둡니다.
- 자동 검사는 모든 개인 정보를 찾아내지 못합니다. **무엇을 옮길지는 사람이 먼저 고르고**, 검사는 마지막 안전망으로 씁니다.
- 이 규칙은 현재 파일에만 적용됩니다. 과거 Git 기록에 남은 내용은 별도로 판단합니다.
