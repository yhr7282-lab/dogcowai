# 검색 유입, 방문자 통계, 수익화 준비

실제 계정 연결과 코드 삽입은 하지 않았다. 아래는 준비 상태와 다음에 할 일이다.
외부 정책은 바뀌므로 실행 전에 공식 문서를 다시 확인한다.

## 검색 (구현됨)
- 페이지마다 고유 제목, 설명, 대표 주소(canonical), Open Graph
- `sitemap.xml`, `robots.txt`, `feed.xml`(Atom), 파비콘
- 404 페이지는 검색 제외(noindex)
- 대표 주소의 기준은 `content/_site.json`의 `base_url` 한 곳이다. HTTPS 인증서가 발급되면 `https://dogcowai.com`으로 바꾸고 다시 생성한다.

## 검색 엔진 등록 (운영자가 직접)
1. HTTPS가 정상인지 확인한다.
2. Google Search Console에 도메인을 등록하고 소유 확인용 TXT 레코드를 Squarespace DNS에 추가한다. 기존 MX·TXT는 지우지 않는다.
3. `https://dogcowai.com/sitemap.xml`을 제출한다.
4. 네이버 서치어드바이저에도 같은 방식으로 등록한다.
사이트맵은 주소 발견을 돕는 수단이고 노출을 보장하지 않는다.

## 방문자 통계 (선택 필요)
지금은 통계 도구가 없다. 방문자 수, 유입 경로, 인기 페이지는 측정 불가 상태다.

| 도구 | 비용 | 특징 |
|---|---|---|
| Cloudflare Web Analytics | 무료 | 스크립트 하나. 쿠키를 쓰지 않는다고 설명. 지금 DNS를 유지해도 설치 가능 |
| GoatCounter | 소규모 무료 | 단순. 약관상 사용 조건 확인 필요 |
| Google Analytics 4 | 무료 | 유입·광고 분석이 자세함. 쿠키 사용, 설정 부담이 큼 |
| Plausible | 유료 | 고정비 0원 원칙과 맞지 않음 |

어느 것을 쓰든 외부 스크립트가 들어가고 소개 페이지의 "방문 기록과 개인정보" 안내를 먼저 고쳐야 한다.
"쿠키 없음"이 곧 "개인정보 의무 없음"은 아니다. 실제 전송 항목과 보관 기간을 확인한 뒤 고지 범위를 정한다.

## 주간 보고 (설계)
저장소만으로 알 수 있는 것: 게시한 브리핑 수, 기사 수, 출처 수, 정정 횟수, 링크 검사 결과.
통계 도구를 붙여야 알 수 있는 것: 방문자, 유입 경로, 인기 페이지, 검색 유입. 연결 전에는 "측정 불가"로 표시한다.

## 광고 수익화 준비
지금은 광고를 넣지 않는다. 먼저 필요한 것:
1. 매일 쌓이는 검증된 브리핑 (가장 중요)
2. 소개·편집 기준·정정 정책 (구현됨), 개인정보 안내 (구현됨, 도구 도입 시 갱신)
3. 방문자 데이터
4. 호스팅 약관 확인: GitHub Pages는 온라인 사업용 무료 호스팅으로 쓰는 것을 제한한다. 광고를 붙이기 전에 GitHub에 확인하거나 Cloudflare Pages 같은 대안으로 옮길지 정한다.
5. 저작권: 원문 문장을 옮기지 않고 직접 쓰며, 사진과 도표는 쓰지 않는다.

광고 승인과 수익은 보장되지 않는다. 방문자 데이터가 없는 지금은 수익을 추정하지 않는다.
